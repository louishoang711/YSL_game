YSL HOLIDAY 26 - OFFLINE VERSION
================================

This package runs the experience fully offline on a Windows PC.
No internet connection is needed.


REQUIREMENTS
------------
- Windows 10 or 11
- Google Chrome installed (any recent version)
- Touchscreen in portrait (vertical) orientation recommended


HOW TO START
------------
1. Extract the whole zip into a folder on the PC (for example the Desktop).
   Do not run it from inside the zip: right click the zip > "Extract All...".
2. Open the extracted folder and double click "start.bat".
3. Chrome opens full screen (kiosk mode) and the experience starts.

The first time, Windows may show "Windows protected your PC".
Click "More info" and then "Run anyway".


HOW TO EXIT
-----------
Press Alt + F4 on a keyboard.


IMPORTANT
---------
- Always start the experience with "start.bat".
  Opening "index.html" directly in a browser will NOT work: the 3D content
  and sounds will not load.
- Keep all files and folders together: "start.bat", "index.html" and the
  "assets" folder must stay in the same folder.
- start.bat opens a separate Chrome window just for this experience, so it
  does not affect the Chrome used for normal browsing.


TROUBLESHOOTING
---------------
- "Google Chrome was not found": install Google Chrome and run start.bat again.
- Black or empty screen: close the window (Alt + F4) and start it again from
  start.bat. Make sure the zip was fully extracted.
- No sound: check the PC volume and that speakers are connected.
